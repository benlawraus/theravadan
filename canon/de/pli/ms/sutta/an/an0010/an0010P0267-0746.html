Aṅguttara Nikāya 10 Nummerierte Lehrreden 10.267–746

23. Rāgapeyyāla 23. Abgekürzte Texte, die mit Gier beginnen

~ Lehrreden ohne Titel über Hass usw.

“Dosassa …pe… „Hass …

mohassa … Täuschung …

kodhassa … Zorn …

upanāhassa … Verbitterung …

makkhassa … Geringschätzung …

paḷāsassa … Verachtung …

issāya … Eifersucht …

macchariyassa … Geiz …

māyāya … Betrug …

sāṭheyyassa … Doppelzüngigkeit …

thambhassa … Starrsinn …

sārambhassa … Angriffslust …

mānassa … Einbildung …

atimānassa … Selbstgefälligkeit …

madassa … Eitelkeit …

pamādassa pariññāya …pe… um Nachlässigkeit vollständig zu verstehen …

parikkhayāya … sie vollständig aufzulösen …

pahānāya … sie aufzugeben …

khayāya … sie aufzulösen …

vayāya … sie zum Verschwinden zu bringen …

virāgāya … zum Schwinden …

nirodhāya … zum Aufhören …

(…) cāgāya … um sie herzugeben …

paṭinissaggāya …pe… um sie loszulassen …

ime dasa dhammā bhāvetabbā”ti. müssen diese zehn Dinge entwickelt werden.“

Rāgapeyyālaṁ niṭṭhitaṁ.

Pañcamo paṇṇāsako samatto.

Dasakanipātapāḷi niṭṭhitā. Das Zehnerbuch ist zu Ende.
