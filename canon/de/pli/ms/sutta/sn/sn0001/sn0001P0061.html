Saṁyutta Nikāya 1.61 Verbundene Lehrreden 1.61

7. Addhavagga 7. Das Kapitel über das Unterdrücken

Nāmasutta Name

“Kiṁsu sabbaṁ addhabhavi, „Was überwindet alles?

kismā bhiyyo na vijjati; Was wird von nichts übertroffen?

Kissassu ekadhammassa, Was ist das eine Ding,

sabbeva vasamanvagū”ti. das alles in seinen Bann schlägt?“

“Nāmaṁ sabbaṁ addhabhavi, „Der Name überwindet alles.

nāmā bhiyyo na vijjati; Der Name wird von nichts übertroffen.

Nāmassa ekadhammassa, Der Name ist das eine Ding,

sabbeva vasamanvagū”ti. das alles in seinen Bann schlägt.“
