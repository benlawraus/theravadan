Saṁyutta Nikāya 22.37 Verbundene Lehrreden 22.37

4. Natumhākavagga 4. Das Kapitel über das, was nicht euer ist

Ānandasutta Mit Ānanda

Sāvatthinidānaṁ. In Sāvatthī.

Atha kho āyasmā ānando …pe… Da ging der Ehrwürdige Ānanda zum Buddha …

ekamantaṁ nisinnaṁ kho āyasmantaṁ ānandaṁ bhagavā etadavoca: Als er sich zur Seite hingesetzt hatte, sagte der Buddha zu ihm:

“Sace taṁ, ānanda, evaṁ puccheyyuṁ: „Ānanda, angenommen, du würdest gefragt:

‘katamesaṁ, āvuso ānanda, dhammānaṁ uppādo paññāyati, vayo paññāyati, ṭhitassa aññathattaṁ paññāyatī’ti? ‚Geehrter Ānanda, was sind die Dinge, bei denen Erscheinen ersichtlich ist, Verschwinden ersichtlich ist und Veränderung während des Bestehens ersichtlich ist?‘

Evaṁ puṭṭho tvaṁ, ānanda, kinti byākareyyāsī”ti? Wie würdest du antworten?“

“Sace maṁ, bhante, evaṁ puccheyyuṁ: „Herr, angenommen, ich würde gefragt:

‘katamesaṁ, āvuso ānanda, dhammānaṁ uppādo paññāyati, vayo paññāyati, ṭhitassa aññathattaṁ paññāyatī’ti? ‚Was sind die Dinge, bei denen Erscheinen ersichtlich ist, Verschwinden ersichtlich ist und Veränderung während des Bestehens ersichtlich ist?‘,

Evaṁ puṭṭhohaṁ, bhante, evaṁ byākareyyaṁ: dann würde ich so antworten:

‘rūpassa kho, āvuso, uppādo paññāyati, vayo paññāyati, ṭhitassa aññathattaṁ paññāyati. ‚Geehrter, das Erscheinen von Form ist ersichtlich, ihr Verschwinden ist ersichtlich und eine Veränderung während ihres Bestehens ist ersichtlich.

Vedanāya … Das Erscheinen von Gefühl ist ersichtlich …

saññāya … Das Erscheinen von Wahrnehmung ist ersichtlich …

saṅkhārānaṁ … Das Erscheinen von Willensbildungsprozessen ist ersichtlich …

viññāṇassa uppādo paññāyati, vayo paññāyati, ṭhitassa aññathattaṁ paññāyati. Das Erscheinen von Bewusstsein ist ersichtlich, sein Verschwinden ist ersichtlich und eine Veränderung während seines Bestehens ist ersichtlich.

Imesaṁ kho, āvuso, dhammānaṁ uppādo paññāyati, vayo paññāyati, ṭhitassa aññathattaṁ paññāyatī’ti. Das sind die Dinge, bei denen Erscheinen ersichtlich ist, Verschwinden ersichtlich ist und Veränderung während des Bestehens ersichtlich ist.‘

Evaṁ puṭṭhohaṁ, bhante, evaṁ byākareyyan”ti. So würde ich eine solche Frage beantworten.“

“Sādhu sādhu, ānanda. „Gut, gut, Ānanda!

Rūpassa kho, ānanda, uppādo paññāyati, vayo paññāyati, ṭhitassa aññathattaṁ paññāyati. Das Erscheinen von Form ist ersichtlich, ihr Verschwinden ist ersichtlich und eine Veränderung während ihres Bestehens ist ersichtlich.

Vedanāya … Das Erscheinen von Gefühl ist ersichtlich …

saññāya … Das Erscheinen von Wahrnehmung ist ersichtlich …

saṅkhārānaṁ … Das Erscheinen von Willensbildungsprozessen ist ersichtlich …

viññāṇassa uppādo paññāyati, vayo paññāyati, ṭhitassa aññathattaṁ paññāyati. Das Erscheinen von Bewusstsein ist ersichtlich, sein Verschwinden ist ersichtlich und eine Veränderung während seines Bestehens ist ersichtlich.

Imesaṁ kho, ānanda, dhammānaṁ uppādo paññāyati, vayo paññāyati, ṭhitassa aññathattaṁ paññāyatīti. Das sind die Dinge, bei denen Erscheinen ersichtlich ist, Verschwinden ersichtlich ist und Veränderung während des Bestehens ersichtlich ist.

Evaṁ puṭṭho tvaṁ, ānanda, evaṁ byākareyyāsī”ti. So sollst du eine solche Frage beantworten.“

Pañcamaṁ.
