Varuṇavagga Das Kapitel über den Wächterbaum

4. Rukkhadhammajātaka Das Gesetz der Bäume: Geschichte aus einem früheren Leben

“Sādhū sambahulā ñātī, Es ist gut für die vielen Verwandten,

api rukkhā araññajā; die Bäume, im Wald geboren.

Vāto vahati ekaṭṭhaṁ, Einen Einzelnen fegt der Wind hinweg,

brahantampi vanappatin”ti. selbst den gewaltigen Fürsten des Waldes.

Rukkhadhammajātakaṁ catutthaṁ.
