Saṁyutta Nikāya 35.152 Связанные Наставления 35.152

15. Navapurāṇavagga Раздел Навапурана

Kimatthiyabrahmacariyasutta Сутта Цель святой жизни

“Sace vo, bhikkhave, aññatitthiyā paribbājakā evaṁ puccheyyuṁ: “Если вас, монахи, отшельники других учений так спросят:

‘kimatthiyaṁ, āvuso, samaṇe gotame brahmacariyaṁ vussatī’ti? 'В чем цель, товарищ, вести святую жизнь при шрамане Готаме'?

Evaṁ puṭṭhā tumhe, bhikkhave, tesaṁ aññatitthiyānaṁ paribbājakānaṁ evaṁ byākareyyātha: Так спрошенные вы, монахи, этим отшельникам других учений так ответьте:

‘dukkhassa kho, āvuso, pariññāya bhagavati brahmacariyaṁ vussatī’ti. 'Для полного понимания, товарищ, боли-дискомфорта ведётся святая жизнь при Благословенном'.

Sace pana vo, bhikkhave, aññatitthiyā paribbājakā evaṁ puccheyyuṁ: Если вас, монахи, отшельники других учений так спросят:

‘katamaṁ panāvuso, dukkhaṁ, yassa pariññāya samaṇe gotame brahmacariyaṁ vussatī’ti? 'Что это, товарщ, за боль, для полного понимания которой при шрамане Готаме ведётся святая жизнь'?

Evaṁ puṭṭhā tumhe, bhikkhave, tesaṁ aññatitthiyānaṁ paribbājakānaṁ evaṁ byākareyyātha: Так спрошенные вы, монахи, этим отшельникам других учений так отвечайте:

‘Cakkhu kho, āvuso, dukkhaṁ; 'Глаз, товарищ, болезнен,

tassa pariññāya bhagavati brahmacariyaṁ vussati. для полного понимания этого при шрамане Готаме святая жизнь ведётся.

Rūpā dukkhā; Объекты болезненны;

tesaṁ pariññāya bhagavati brahmacariyaṁ vussati. для полного понимания этих при шрамане Готаме святая жизнь ведётся..

Cakkhuviññāṇaṁ dukkhaṁ; Внимание глаза болезненно;

tassa pariññāya bhagavati brahmacariyaṁ vussati. для полного понимания этого при шрамане Готаме святая жизнь ведётся..

Cakkhusamphasso dukkho; Соприкосновение глаза болезненно;

tassa pariññāya bhagavati brahmacariyaṁ vussati. для полного понимания этого при шрамане Готаме святая жизнь ведётся.

Yampidaṁ cakkhusamphassapaccayā uppajjati vedayitaṁ sukhaṁ vā dukkhaṁ vā adukkhamasukhaṁ vā tampi dukkhaṁ; То, что от соприкосновения глаза порождает ощущающееся приятное, боль, либо ни-боль-ни-приятное, это в том числе болезненно.

tassa pariññāya bhagavati brahmacariyaṁ vussati …pe… Для полного понимания этого при шрамане Готаме святая жизнь ведётся…

jivhā dukkhā … язык болезнен…

mano dukkho; ум-представление болезнен…

tassa pariññāya bhagavati brahmacariyaṁ vussati … для полного понимания этого при шрамане Готаме святая жизнь ведётся…

yampidaṁ manosamphassapaccayā uppajjati vedayitaṁ sukhaṁ vā dukkhaṁ vā adukkhamasukhaṁ vā tampi dukkhaṁ; То, что от соприкосновения ума порождает ощущающееся приятное, боль, либо ни-боль-ни-приятное, это в том числе боль.

tassa pariññāya bhagavati brahmacariyaṁ vussati. Для полного понимания этого при шрамане Готаме святая жизнь ведётся.

Idaṁ kho, āvuso, dukkhaṁ; Это та, товарищ, боль,

yassa pariññāya bhagavati brahmacariyaṁ vussatī’ti. для полного понимания которой при шрамане Готаме святая жизнь ведётся.

Evaṁ puṭṭhā tumhe, bhikkhave, tesaṁ aññatitthiyānaṁ paribbājakānaṁ evaṁ byākareyyāthā”ti. Так спрошенные вы, монахи, этим отшельникам других учений так отвечайте.

Sattamaṁ. Седьмая.
