Saṁyutta Nikāya 35.68 Связанные Наставления 35.68

7. Migajālavagga Раздел Мигалджала

Samiddhilokapañhāsutta Сутта Вопрос Самиддхи о Свете-Мире

“‘Loko, loko’ti, bhante, vuccati. “‘Свет, свет’, почтенный, говорится.

Kittāvatā nu kho, bhante, loko vā assa lokapaññatti vā”ti? До какой степени, почтенный, может быть свет либо понятие света”?

“Yattha kho, samiddhi, atthi cakkhu, atthi rūpā, atthi cakkhuviññāṇaṁ, atthi cakkhuviññāṇaviññātabbā dhammā, atthi tattha loko vā lokapaññatti vāti …pe… “Когда, Самиддхи, есть глаз, есть объекты, есть внимание глаза, есть вниманием глаза распознаваемые явления, там есть свет, либо понятие света…

atthi jivhā …pe… есть язык…

atthi mano, atthi dhammā, atthi manoviññāṇaṁ, atthi manoviññāṇaviññātabbā dhammā, atthi tattha loko vā lokapaññatti vā. есть ум-представление, есть явления, есть умственное внимание, есть умственным вниманием распознаваемые явления, там есть свет, либо понятие света.

Yattha ca kho, samiddhi, natthi cakkhu, natthi rūpā, natthi cakkhuviññāṇaṁ, natthi cakkhuviññāṇaviññātabbā dhammā, natthi tattha loko vā lokapaññatti vā …pe… Где, Самиддхи, нет глаза, нет объектов, нет внимания глаза, нет вниманием глаза распознаваемых явлений, там нет света, либо понятие света…

natthi jivhā …pe… нет языка…

natthi mano, natthi dhammā, natthi manoviññāṇaṁ, natthi manoviññāṇaviññātabbā dhammā, natthi tattha loko vā lokapaññatti vā”ti. нет ума, нет явлений, нет умственного внимания, нет умственным вниманием распознаваемых явлений, там нет света, либо понятие света”.

Chaṭṭhaṁ. Шестая.
