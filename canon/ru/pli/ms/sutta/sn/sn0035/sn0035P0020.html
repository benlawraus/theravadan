Saṁyutta Nikāya 35.20 Связанные Наставления 35.20

2. Yamakavagga Раздел Ямака

Dutiyābhinandasutta Сутта Обрадование Вторая

“Yo, bhikkhave, rūpe abhinandati, dukkhaṁ so abhinandati. “Который, монахи, объектам-видам радуется (обрадывается), боли тот радуется.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. Который боли радуется, 'не освобожден тот от боли - это' говорю.

Yo sadde …pe… Который звукам…

gandhe … запахам…

rase … вкусам…

phoṭṭhabbe … касаниям…

dhamme abhinandati, dukkhaṁ so abhinandati. Явлениям радуется, боли тот радуется.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. Который боли радуется, 'не освобожден тот от боли - это' говорю.

“Yo ca kho, bhikkhave, rūpe nābhinandati, dukkhaṁ so nābhinandati. А который, монахи, объектам не радуется, боли тот не радуется.

Yo dukkhaṁ nābhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. Который боли не радуется, 'освобожден тот от боли - это' говорю.

Yo sadde …pe… Который звукам…

gandhe … запахам…

rase … вкусам…

phoṭṭhabbe … касаниям…

dhamme nābhinandati, dukkhaṁ so nābhinandati. Явлениям не радуется, боли тот не радуется.

Yo dukkhaṁ nābhinandati, ‘aparimutto so dukkhasmā’ti vadāmi.” Который боли не радуется, 'освобожден тот от боли - это' говорю.

Aṭṭhamaṁ. Восьмая.
