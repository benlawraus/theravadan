Saṁyutta Nikāya 45.180 Связанные Наставления 45.180

14. Oghavagga Раздел Есана

Uddhambhāgiyasutta Сутта Восходящее Отношение

“Pañcimāni, bhikkhave, uddhambhāgiyāni saṁyojanāni. “Есть пять, монахи, относящихся к восходящему связанностей.

Katamāni pañca? Какие пять?

Rūparāgo, arūparāgo, māno, uddhaccaṁ, avijjā—Очарованность материей, очарованность нематериальным, самомнение, возбуждённость, неразличение—

imāni kho, bhikkhave, pañcuddhambhāgiyāni saṁyojanāni. Эти пять, монахи, относящихся к восходящему связанностей.

Imesaṁ kho, bhikkhave, pañcannaṁ uddhambhāgiyānaṁ saṁyojanānaṁ abhiññāya pariññāya parikkhayāya pahānāya ariyo aṭṭhaṅgiko maggo bhāvetabbo. Для этих, монахи, пяти относящихся к восходящему связанностей познания, полного понимания, полного исчерпания, покидания этот Благородный Восьмеричный Путь должен быть развит.

Katamo ariyo aṭṭhaṅgiko maggo? Какой Благородный Восьмеричный Путь?

Idha, bhikkhave, bhikkhu sammādiṭṭhiṁ bhāveti vivekanissitaṁ …pe… sammāsamādhiṁ bhāveti vivekanissitaṁ virāganissitaṁ nirodhanissitaṁ vossaggapariṇāmiṁ. Вот, монахи, монах развивает правильный взгляд, основанный на разъединении… правильное объединение опыта, основанное на разъединении, бесстрастии, устранении, созревающее в оставлении.

Imesaṁ kho, bhikkhave, pañcannaṁ uddhambhāgiyānaṁ saṁyojanānaṁ abhiññāya pariññāya parikkhayāya pahānāya ayaṁ ariyo aṭṭhaṅgiko maggo bhāvetabboti. Для этих, монахи, пяти относящихся к восходящему связанностей познания, полного понимания, полного исчерпания, покидания этот Благородный Восьмеричный Путь должен быть развит.

Pañcimāni, bhikkhave, uddhambhāgiyāni saṁyojanāni. “Есть пять, монахи, относящихся к восходящему связанностей.

Katamāni pañca? Какие пять?

Rūparāgo, arūparāgo, māno, uddhaccaṁ, avijjā—Очарованность материей, очарованность нематериальным, самомнение, возбуждённость, неразличение—

imāni kho, bhikkhave, pañcuddhambhāgiyāni saṁyojanāni. Эти пять, монахи, относящихся к восходящему связанностей.

Imesaṁ kho, bhikkhave, pañcannaṁ uddhambhāgiyānaṁ saṁyojanānaṁ abhiññāya pariññāya parikkhayāya pahānāya ariyo aṭṭhaṅgiko maggo bhāvetabbo. Для этих, монахи, пяти относящихся к восходящему связанностей познания, полного понимания, полного исчерпания, покидания этот Благородный Восьмеричный Путь должен быть развит.

Katamo ariyo aṭṭhaṅgiko maggo? Какой Благородный Восьмеричный Путь?

Idha, bhikkhave, bhikkhu sammādiṭṭhiṁ bhāveti …pe… sammāsamādhiṁ bhāveti rāgavinayapariyosānaṁ dosavinayapariyosānaṁ mohavinayapariyosānaṁ … Вот, монахи, монах развивает правильный взгляд… правильное объединение опыта, имеющее целью выведение страсти, имеющее целью выведение злобы, имеющее целью выведение замутнённости…

amatogadhaṁ amataparāyanaṁ amatapariyosānaṁ … который имеет Бессмертное своим основанием, Бессмертное своим пунктом назначения, Бессмертное окончательной целью…

nibbānaninnaṁ nibbānapoṇaṁ nibbānapabbhāraṁ. направляющийся к ниббане, склоняющийся к ниббане, устремляющийся к ниббане.

Imesaṁ kho, bhikkhave, pañcannaṁ uddhambhāgiyānaṁ saṁyojanānaṁ abhiññāya pariññāya parikkhayāya pahānāya ayaṁ ariyo aṭṭhaṅgiko maggo bhāvetabbo”ti. Для этих, монахи, пяти относящихся к восходящему связанностей познания, полного понимания, полного исчерпания, покидания этот Благородный Восьмеричный Путь должен быть развит”.

Dasamaṁ. Десятая.

Oghavaggo aṭṭhamo. Глава Огха Восьмая.

Tassuddānaṁ Оглавление

Ogho yogo upādānaṁ, Наводнение, связь, поддерживание,

ganthaṁ anusayena ca; узел и залежь;

Kāmaguṇā nīvaraṇaṁ, Множитель желания, покров;

khandhā oruddhambhāgiyāti. блок, относящийся к ближне-восходящему

vagguddānaṁ Список глав

Avijjāvaggo paṭhamo,

dutiyaṁ vihāraṁ vuccati;

Micchattaṁ tatiyo vaggo,

catutthaṁ paṭipanneneva.

Titthiyaṁ pañcamo vaggo,

chaṭṭho sūriyena ca;

Bahukate sattamo vaggo,

uppādo aṭṭhamena ca.

Divasavaggo navamo,

Dasamo appamādena ca;

Ekādasabalavaggo,

Dvādasa esanā pāḷiyaṁ;

Oghavaggo bhavati terasāti.

Maggasaṁyuttaṁ paṭhamaṁ. Маггасаньютта Первая.
