Saṁyutta Nikāya 12.83–92 Связанные Наставления 12.83-92

9. Antarapeyyāla Сокращение Антара

Dutiyasatthusuttādidasaka Десятка Сутт начинающихся с Учитель Вторая

“Jātiṁ, bhikkhave, ajānatā apassatā yathābhūtaṁ …pe…. Рождение, монахи, как-есть незнающий невидящий…

“Bhavaṁ, bhikkhave, ajānatā apassatā yathābhūtaṁ …pe…. Бхаву, монахи, как-есть незнающий невидящий…

“Upādānaṁ, bhikkhave, ajānatā apassatā yathābhūtaṁ …pe…. Поддерживание, монахи, как-есть незнающий невидящий…

“Taṇhaṁ, bhikkhave, ajānatā apassatā yathābhūtaṁ …pe…. Цепляние, монахи, как-есть незнающий невидящий…

“Vedanaṁ, bhikkhave, ajānatā apassatā yathābhūtaṁ …pe…. Ведание, монахи, как-есть незнающий невидящий…

“Phassaṁ, bhikkhave, ajānatā apassatā yathābhūtaṁ …pe…. Касание, монахи, как-есть незнающий невидящий…

“Saḷāyatanaṁ, bhikkhave, ajānatā apassatā yathābhūtaṁ …pe…. Шестеричную область, монахи, как-есть незнающий невидящий…

“Nāmarūpaṁ, bhikkhave, ajānatā apassatā yathābhūtaṁ …pe…. Имя-рупа, монахи, как-есть незнающий невидящий…

“Viññāṇaṁ, bhikkhave, ajānatā apassatā yathābhūtaṁ …pe…. Внимание, монахи, как-есть незнающий невидящий…

“Saṅkhāre, bhikkhave, ajānatā apassatā yathābhūtaṁ saṅkhāresu yathābhūtaṁ ñāṇāya satthā pariyesitabbo; Отождествления, монахи, как-есть незнающий невидящий для знания отождествлений как-есть должен найти учителя;

saṅkhārasamudayaṁ ajānatā apassatā yathābhūtaṁ saṅkhārasamudaye yathābhūtaṁ ñāṇāya satthā pariyesitabbo; Скапливание отождествлений, монахи, как-есть незнающий невидящий для знания скапливания отождествлений как-есть должен найти учителя;

saṅkhāranirodhaṁ ajānatā apassatā yathābhūtaṁ saṅkhāranirodhe yathābhūtaṁ ñāṇāya satthā pariyesitabbo; Устранение отождествлений, монахи, как-есть незнающий невидящий для знания устранения отождествлений как-есть должен найти учителя;

saṅkhāranirodhagāminiṁ paṭipadaṁ ajānatā apassatā yathābhūtaṁ saṅkhāranirodhagāminiyā paṭipadāya yathābhūtaṁ ñāṇāya satthā pariyesitabbo”ti. К устранению отождествлений ведущую практику, монахи, как-есть незнающий невидящий для знания к устранению отождествлений ведущей практики как-есть должен найти учителя;

Ekādasamaṁ. Одиннадцатая.

(Sabbesaṁ catusaccikaṁ kātabbaṁ.) (Все по Четырём Благородным Истинам должны быть сделанны.)
