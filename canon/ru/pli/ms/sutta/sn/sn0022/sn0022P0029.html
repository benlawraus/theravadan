Saṁyutta Nikāya 22.29 Связанные Наставления 22.29

3. Bhāravagga Раздел Бхара

Abhinandanasutta Сутта Обрадование

Sāvatthinidānaṁ. В обстоятельствах Саваттхи.

“Yo, bhikkhave, rūpaṁ abhinandati, dukkhaṁ so abhinandati. “Который, монахи, объекту (материи-энергии, виду) радуется (обрадывается), боли тот радуется.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. Который боли радуется, 'не освобожден тот от боли - это' говорю.

Yo vedanaṁ abhinandati … Который чувствованию радуется…

yo saññaṁ abhinandati … который сознаванию радуется…

yo saṅkhāre abhinandati … который составляющим радуется…

yo viññāṇaṁ abhinandati, dukkhaṁ so abhinandati. который вниманию-распознаванию радуется, боли тот радуется.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. Который боли радуется, 'не освобожден тот от боли - это' говорю.

Yo ca kho, bhikkhave, rūpaṁ nābhinandati, dukkhaṁ so nābhinandati. А который, монахи, объекту не радуется, боли тот не радуется.

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmi. Который боли не радуется, 'освобожден тот от боли - это' говорю.

Yo vedanaṁ nābhinandati … Который чувствованию не радуется…

yo saññaṁ nābhinandati … который сознаванию не радуется…

yo saṅkhāre nābhinandati … который составляющим не радуется…

yo viññāṇaṁ nābhinandati, dukkhaṁ so nābhinandati. который вниманию не радуется, боли тот не радуется.

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmī”ti. Который боли не радуется, 'освобожден тот от боли - это' говорю.

Aṭṭhamaṁ. Восьмая.
