Saṁyutta Nikāya 14.35 Связанные Наставления 14.35

4. Catutthavagga Раздел Четвёртый

Abhinandasutta Сутта Обрадование

Sāvatthiyaṁ viharati. В Саваттхи располагается.

“Yo, bhikkhave, pathavīdhātuṁ abhinandati, dukkhaṁ so abhinandati. “Который, монахи, твердого (земли)-дхату (явлению, феномену) радуется (обрадывается), боли тот радуется.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. Который боли радуется, 'не освобожден тот от боли - это' говорю.

Yo āpodhātuṁ abhinandati …pe… Который жидкости-дхату радуется…

yo tejodhātuṁ … который тепла-дхату…

yo vāyodhātuṁ abhinandati, dukkhaṁ so abhinandati. который ветра-дхату радуется, боли тот радуется.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. Который боли радуется, 'не освобожден тот от боли - это' говорю.

Yo ca kho, bhikkhave, pathavīdhātuṁ nābhinandati, dukkhaṁ so nābhinandati. А который, монахи, твердого-дхату не радуется, боли тот не радуется.

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmi. Который боли не радуется, 'освобожден тот от боли - это' говорю.

Yo āpodhātuṁ …pe… Который жидкости-дхату не радуется…

yo tejodhātuṁ … который тепла-дхату…

yo vāyodhātuṁ nābhinandati, dukkhaṁ so nābhinandati. который ветра-дхату не радуется, боли тот не радуется.

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmī”ti. Который боли не радуется, 'освобожден тот от боли - это' говорю.

Chaṭṭhaṁ. Шестая.
