11. Rāgapeyyāla Сокращение Страсть Сокращение Страсть

~

“Rāgassa, bhikkhave, pariññāya …pe… Для полного понимания страсти, монахи… Для полного понимания страсти, монахи…

parikkhayāya … исчерпывания… исчерпывания…

pahānāya … покидания… покидания…

khayāya … исчерпания… исчерпания…

vayāya … исчезновения… исчезновения…

virāgāya … бесстрастия… бесстрастия…

nirodhāya … истечения… устранения…

cāgāya …pe… отказа… отказа…
