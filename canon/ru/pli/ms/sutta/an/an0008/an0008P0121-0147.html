Aṅguttara Nikāya 8 Восходящие Наставления 8.121-147

11. Rāgapeyyāla Сокращение Страсть

~

“Rāgassa, bhikkhave, pariññāya …pe… Для полного понимания страсти, монахи, восемь явлений должны быть развиты…

parikkhayāya … исчерпывания…

pahānāya … покидания…

khayāya … исчерпания…

vayāya … исчезновения…

virāgāya … бесстрастия…

nirodhāya … устранения…

cāgāya … отказа…

paṭinissaggāya …pe… отдаления…

ime aṭṭha dhammā bhāvetabbā”. эти восемь явлений должны быть развиты.
