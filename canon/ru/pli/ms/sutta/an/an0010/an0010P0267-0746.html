Aṅguttara Nikāya 10 Восходящие Наставления 10.267-746

23. Rāgapeyyāla Сокращение Страсть

~

“Dosassa …pe… Злобы…

mohassa … заблуждения…

kodhassa … ворчания…

upanāhassa … жестокости…

makkhassa … умаления…

paḷāsassa … завистливого соперничества…

issāya … ревности…

macchariyassa … жадности…

māyāya … притворства…

sāṭheyyassa … хитрости…

thambhassa … упрямства…

sārambhassa … агрессии…

mānassa … самомнения…

atimānassa … завышенной самооценки…

madassa … опьянения

pamādassa pariññāya …pe… беспечности полного понимания…

parikkhayāya … исчерпывания…

pahānāya … покидания…

khayāya … исчерпания…

vayāya … исчезновения…

virāgāya … бесстрастия…

nirodhāya … устранения…

(…) cāgāya … отказа…

paṭinissaggāya …pe… отдаления…

ime dasa dhammā bhāvetabbā”ti. эти десять явлений должны быть развиты.

Rāgapeyyālaṁ niṭṭhitaṁ. Сокращение Страсть Закончено.

Pañcamo paṇṇāsako samatto. Пятая Пятидесятка Завершена.

Dasakanipātapāḷi niṭṭhitā. Собрание Десяток Закончено.
