28. Rāgapeyyāla Сокращение Страсть

Pariññādisutta Сутта Полное Понимание

“Rāgassa, bhikkhave, pariññāya …pe… parikkhayāya … pahānāya … khayāya … vayāya … virāgāya … nirodhāya … cāgāya … paṭinissaggāya cattāro dhammā bhāvetabbā …pe…. Для страсти, монахи, полного понимания… исчерпывания… покидания… исчерпания… исчезновения… бесстрастия… устранения… отказа… отдаления четыре явления должны быть развиты…

Tiṁsatimaṁ. Тринадцатая.
