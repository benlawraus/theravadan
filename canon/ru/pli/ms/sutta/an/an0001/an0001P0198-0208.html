Aṅguttara Nikāya 1 Ангуттара Никая 1

15. Dutiyavagga 15. Вторая глава

“Etadaggaṁ, bhikkhave, mama sāvakānaṁ bhikkhūnaṁ manomayaṁ kāyaṁ abhinimminantānaṁ yadidaṁ cūḷapanthako. «Монахи, самым выдающимся моим учеником среди монахов, порождающих тело, созданное из-разума, является Чуллапантхака».

… Cetovivaṭṭakusalānaṁ yadidaṁ cūḷapanthako. … которые умелые в умственном преобразовании, является Чуллапантхака».

… Saññāvivaṭṭakusalānaṁ yadidaṁ mahāpanthako. … умелых в преобразовании восприятия, является Махапантхака».

… Araṇavihārīnaṁ yadidaṁ subhūti. … которые живут без конфликтов, является Субхути».

… Dakkhiṇeyyānaṁ yadidaṁ subhūti. … которые наиболее достойны даров, является Субхути».

… Āraññakānaṁ yadidaṁ revato khadiravaniyo. … которые проживают в лесу, является Ревата Кхадиравания».

… Jhāyīnaṁ yadidaṁ kaṅkhārevato. … которые медитируют, является Канкхаревата».

… Āraddhavīriyānaṁ yadidaṁ soṇo koḷiviso. … которые зарождают усердие, является Сона Коливиса».

… Kalyāṇavākkaraṇānaṁ yadidaṁ soṇo kuṭikaṇṇo. … которые являются превосходными ораторами, является Сона Кутиканна».

… Lābhīnaṁ yadidaṁ sīvali. … которые получают обретения, является Сивали».

… Saddhādhimuttānaṁ yadidaṁ vakkalī”ti. … которые обрели решительность посредством веры, является Ваккали».

Vaggo dutiyo.
