Aṅguttara Nikāya 1 Ангуттара Никая 1

16. Tatiyavagga 16. Третья глава

“Etadaggaṁ, bhikkhave, mama sāvakānaṁ bhikkhūnaṁ sikkhākāmānaṁ yadidaṁ rāhulo. «Монахи, самым выдающимся моим учеником среди монахов, которые больше других желают тренироваться, является Рахула».

… Saddhāpabbajitānaṁ yadidaṁ raṭṭhapālo. … которые ушли в бездомную жизнь благодаря вере, является Раттхапала».

… Paṭhamaṁ salākaṁ gaṇhantānaṁ yadidaṁ kuṇḍadhāno. … которые первыми достают обеденный билет, является Кундадхана».

… Paṭibhānavantānaṁ yadidaṁ vaṅgīso. … которые сочиняют вдохновенные строфы, является Вангиса».

… Samantapāsādikānaṁ yadidaṁ upaseno vaṅgantaputto. … которые во всех отношениях внушают доверие, является Упасена Вангантапутта».

… Senāsanapaññāpakānaṁ yadidaṁ dabbo mallaputto. … которые распределяют жилища, является Дабба Маллапутта».

… devatānaṁ piyamanāpānaṁ yadidaṁ pilindavaccho. … которые милы и приятны божествам, является Пилиндаваччха».

… Khippābhiññānaṁ yadidaṁ bāhiyo dārucīriyo. … которые быстро достигают прямого знания, является Бахия Даручирия».

… Cittakathikānaṁ yadidaṁ kumārakassapo. … которые обладают пёстрой речью, является Кумара Кассапа».

… Paṭisambhidāpattānaṁ yadidaṁ mahākoṭṭhito”ti. … которые достигли аналитических знаний, является Махакоттхита».

Vaggo tatiyo.
