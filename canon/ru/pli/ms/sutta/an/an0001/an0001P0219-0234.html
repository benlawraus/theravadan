Aṅguttara Nikāya 1 Ангуттара Никая 1

17. Catutthavagga 17. Четвертая глава

“Etadaggaṁ, bhikkhave, mama sāvakānaṁ bhikkhūnaṁ bahussutānaṁ yadidaṁ ānando. «Монахи, самым выдающимся моим учеником среди монахов, которые учёные, является Ананда».

… Satimantānaṁ yadidaṁ ānando. … которые обладают хорошей памятью, является Ананда».

… Gatimantānaṁ yadidaṁ ānando. … которые быстро схватывают учения, является Ананда».

… Dhitimantānaṁ yadidaṁ ānando. … которые решительны, является Ананда».

… Upaṭṭhākānaṁ yadidaṁ ānando. … которые являются личными прислужниками, является Ананда».

… Mahāparisānaṁ yadidaṁ uruvelakassapo. … с большой свитой, является Урувела Кассапа».

… Kulappasādakānaṁ yadidaṁ kāḷudāyī. … которые пробуждают доверие в семьях, является Калудайи».

… Appābādhānaṁ yadidaṁ bākulo. … которые обладают хорошим здоровьем, является Баккула».

… Pubbenivāsaṁ anussarantānaṁ yadidaṁ sobhito. … которые вспоминают свои прошлые жизни, является Собхита».

… Vinayadharānaṁ yadidaṁ upāli. … которые являются поборниками Винаи, является Упали».

… Bhikkhunovādakānaṁ yadidaṁ nandako. … которые наставляют монахинь, является Нандака».

… Indriyesu guttadvārānaṁ yadidaṁ nando. … которые лучше других охраняют двери способностей [органов] чувств, является Нанда».

… Bhikkhuovādakānaṁ yadidaṁ mahākappino. … которые дают советы монахам, является Махакаппина».

… Tejodhātukusalānaṁ yadidaṁ sāgato. … с умением в элементе огня, является Сагата».

… Paṭibhāneyyakānaṁ yadidaṁ rādho. … которым дают красноречивые проповеди, является Радха».

… Lūkhacīvaradharānaṁ yadidaṁ mogharājā”ti. … которые носят грубые одежды, является Могхараджа».

Vaggo catuttho.
