Aṅguttara Nikāya 1 Ангуттара Никая 1

18. Pañcamavagga 18. Пятая глава

“Etadaggaṁ, bhikkhave, mama sāvikānaṁ bhikkhunīnaṁ rattaññūnaṁ yadidaṁ mahāpajāpatigotamī. «Монахи, самой выдающейся моей ученицей среди монахинь плане старшинства является Махападжапати Готами».

… Mahāpaññānaṁ yadidaṁ khemā. … которые обладают великой мудростью, является Кхема».

… Iddhimantīnaṁ yadidaṁ uppalavaṇṇā. … которые обладают сверхъестественными силами, является Уппалаванна».

… Vinayadharānaṁ yadidaṁ paṭācārā. … которые являются поборниками Винаи, является Патачара».

… Dhammakathikānaṁ yadidaṁ dhammadinnā. … которые являются ораторами Дхаммы, является Дхаммадинна».

… Jhāyīnaṁ yadidaṁ nandā. … которые медитируют, является Нанда».

… Āraddhavīriyānaṁ yadidaṁ soṇā. … которые зарождают усердие, является Сона».

… Dibbacakkhukānaṁ yadidaṁ bakulā. … которые обладают божественным глазом, является Сакула».

… Khippābhiññānaṁ yadidaṁ bhaddā kuṇḍalakesā. … которые быстро достигают прямого знания, является Бхадда Кундалакеса».

… Pubbenivāsaṁ anussarantīnaṁ yadidaṁ bhaddā kāpilānī. … которые вспоминают прошлые жизни, является Бхадда Капилани».

… Mahābhiññāpattānaṁ yadidaṁ bhaddakaccānā. … которые достигают великого прямого знания, является Бхадда Каччана».

… Lūkhacīvaradharānaṁ yadidaṁ kisāgotamī. … которые носят грубые одежды, является Кисаготами».

… Saddhādhimuttānaṁ yadidaṁ siṅgālakamātā”ti. … которые обрели решительность посредством веры, является Сигаламата».

Vaggo pañcamo.
