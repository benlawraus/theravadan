Aṅguttara Nikāya 1 Ангуттара Никая 1

23. Tatiyavagga 23. Третья глава

287

“Aṭṭhānametaṁ, bhikkhave, anavakāso yaṁ kāyasucaritassa aniṭṭho akanto amanāpo vipāko nibbatteyya. Netaṁ ṭhānaṁ vijjati. «Монахи, не может быть такого, немыслимо, чтобы нежелательный, нежеланный, неприятный результат мог бы произойти из благого телесного поведения. Нет такой возможности.

Ṭhānañca kho etaṁ, bhikkhave, vijjati yaṁ kāyasucaritassa iṭṭho kanto manāpo vipāko nibbatteyya. Ṭhānametaṁ vijjatī”ti. Но может быть так, что желаемый, желанный, приятный результат произойдёт из благого телесного поведения. Есть такая возможность».

288–289 288-289

“Aṭṭhānametaṁ, bhikkhave, anavakāso yaṁ vacīsucaritassa …pe… manosucaritassa aniṭṭho akanto amanāpo vipāko nibbatteyya. Netaṁ ṭhānaṁ vijjati. «Монахи, не может быть такого, немыслимо, чтобы нежелательный, нежеланный, неприятный результат мог бы произойти из благого словесного… благого умственного поведения. Нет такой возможности.

Ṭhānañca kho etaṁ, bhikkhave, vijjati yaṁ manosucaritassa iṭṭho kanto manāpo vipāko nibbatteyya. Ṭhānametaṁ vijjatī”ti. Но может быть так, что желаемый, желанный, приятный результат произойдёт из благого словесного … благого умственного поведения. Есть такая возможность».

290

“Aṭṭhānametaṁ, bhikkhave, anavakāso yaṁ kāyaduccaritasamaṅgī tannidānā tappaccayā kāyassa bhedā paraṁ maraṇā sugatiṁ saggaṁ lokaṁ upapajjeyya. Netaṁ ṭhānaṁ vijjati. «Монахи, не может быть такого, немыслимо, чтобы человек, который пускается в неблагое телесное поведение, в этом случае, по этой причине, с распадом тела, после смерти, переродился в счастливом уделе, в небесном мире. Нет такой возможности.

Ṭhānañca kho etaṁ, bhikkhave, vijjati yaṁ kāyaduccaritasamaṅgī tannidānā tappaccayā kāyassa bhedā paraṁ maraṇā apāyaṁ duggatiṁ vinipātaṁ nirayaṁ upapajjeyya. Ṭhānametaṁ vijjatī”ti. Но может быть так, что человек, который пускается в неблагое телесное поведение в этом случае, по этой причине, с распадом тела, после смерти, переродится в состоянии лишений, в несчастливом уделе, в нижних мирах, даже в аду. Есть такая возможность».
