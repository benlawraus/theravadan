Aṅguttara Nikāya 1 Ангуттара Никая 1

28. Pasādakaradhammavagga 28. Качества, внушающие доверие

“Addhamidaṁ, bhikkhave, lābhānaṁ yadidaṁ āraññikattaṁ …pe… «Монахи, вне сомнений, это один из видов обретений, а именно быть тем, кто проживает в лесу …

piṇḍapātikattaṁ … тем кто живёт едой, полученной с хождения за подаяниями …

paṁsukūlikattaṁ … тем кто носит обноски …

tecīvarikattaṁ … тем кто имеет только три одеяния …

dhammakathikattaṁ … кто проповедует Дхамму …

vinayadharattaṁ … поборником Винаи …

bāhusaccaṁ … тем кто обладает великой учёностью …

thāvareyyaṁ … тем кто давно находится в монашестве…

ākappasampadā … тем кто обладает подобающими манерами …

parivārasampadā … кто обретает свиту последователей …

mahāparivāratā … тем кто имеет большую свиту …

kolaputti … тем кто происходит из хорошей семьи …

vaṇṇapokkharatā … привлекательным …

kalyāṇavākkaraṇatā … превосходным оратором …

appicchatā … тем, кто имеет малочисленность желаний …

appābādhatā”ti. тем, кто имеет хорошее здоровье».

(Soḷasa pasādakaradhammā niṭṭhitā.)
