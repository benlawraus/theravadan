Aṅguttara Nikāya 1 Ангуттара Никая 1

14. Paṭhamavagga 14. Первая глава

“Etadaggaṁ, bhikkhave, mama sāvakānaṁ bhikkhūnaṁ rattaññūnaṁ yadidaṁ aññāsikoṇḍañño. «Монахи, самым выдающимся моим учеником среди монахов в плане старшинства является Аннякондання.

… Mahāpaññānaṁ yadidaṁ sāriputto. … которые обладают великой мудростью, является Сарипутта».

… Iddhimantānaṁ yadidaṁ mahāmoggallāno. … которые обладают сверхъестественными силами, является Махамоггаллана»

… Dhutavādānaṁ yadidaṁ mahākassapo. … которые разъясняют аскетические практики, является Махакассапа».

… Dibbacakkhukānaṁ yadidaṁ anuruddho. … которые обладают божественным глазом, является Ануруддха».

… Uccākulikānaṁ yadidaṁ bhaddiyo kāḷigodhāya putto. … которые происходят из знатных семей, является Бхаддия Калигодхаяпутта».

… Mañjussarānaṁ yadidaṁ lakuṇḍaka bhaddiyo. … которые обладают приятным голосом, является Лакунтака Бхаддия».

… Sīhanādikānaṁ yadidaṁ piṇḍolabhāradvājo. … которые рычат львиным рыком, является Пиндола Бхарадваджа».

… Dhammakathikānaṁ yadidaṁ puṇṇo mantāṇiputto. … которые являются ораторами Дхаммы, является Пунна Мантанипутта».

… saṅkhittena bhāsitassa vitthārena atthaṁ vibhajantānaṁ yadidaṁ mahākaccāno”ti. … которые объясняют в подробностях то, о чём было сказано кратко, является Махакаччана».

Vaggo paṭhamo.
