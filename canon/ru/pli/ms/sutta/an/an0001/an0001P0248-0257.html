Aṅguttara Nikāya 1 Ангуттара Никая 1

19. Chaṭṭhavagga 19. Шестая глава

“Etadaggaṁ, bhikkhave, mama sāvakānaṁ upāsakānaṁ paṭhamaṁ saraṇaṁ gacchantānaṁ yadidaṁ tapussabhallikā vāṇijā. «Монахи, самыми выдающимися моими учениками среди мирян в плане того, кто первым принял прибежище, являются купцы Тапусса и Бхаллика».

… Dāyakānaṁ yadidaṁ sudatto gahapati anāthapiṇḍiko. … которые являются жертвователями, является домохозяин Судатта Анатхапиндика».

… Dhammakathikānaṁ yadidaṁ citto gahapati macchikāsaṇḍiko. … которые являются ораторами Дхаммы, является домохозяин Читта из Маччхикасанды».

… Catūhi saṅgahavatthūhi parisaṁ saṅgaṇhantānaṁ yadidaṁ hatthako āḷavako. … которые используют четыре средства привлечения и поддержания других, является Хаттхака из Алави».

… Paṇītadāyakānaṁ yadidaṁ mahānāmo sakko. … которые дарят превосходные вещи, является Маханама из клана Сакьев».

… Manāpadāyakānaṁ yadidaṁ uggo gahapati vesāliko. … которые дарят приятные вещи, является Угга из Весали».

… Saṅghupaṭṭhākānaṁ yadidaṁ hatthigāmako uggato gahapati. … которые прислуживают Сангхе, является домохозяин Уггата».

… Aveccappasannānaṁ yadidaṁ sūrambaṭṭho. … которые обладают непоколебимым доверием, является Сура Амбаттха».

… Puggalappasannānaṁ yadidaṁ jīvako komārabhacco. … которые обладают доверием к людям, является Дживака Комарабхачча».

… Vissāsakānaṁ yadidaṁ nakulapitā gahapatī”ti. … которые заслуживают доверия, является домохозяин Накулапита».

Vaggo chaṭṭho.
