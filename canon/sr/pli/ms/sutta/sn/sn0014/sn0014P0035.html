Saṁyutta Nikāya 14.35 Budini govori tematski grupisani 14.35

4. Catutthavagga 4. Četvrto poglavlje

Abhinandasutta Oduševljenje

Sāvatthiyaṁ viharati. Kraj Sāvatthīja.

“Yo, bhikkhave, pathavīdhātuṁ abhinandati, dukkhaṁ so abhinandati. „Monasi, onaj ko se oduševljava elementom zemlje, oduševljava se patnjom.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. A onaj ko se oduševljava patnjom, kažem vam, ne oslobađa se patnje.

Yo āpodhātuṁ abhinandati …pe… Onaj ko se oduševljava elementom vode…

yo tejodhātuṁ … Onaj ko se oduševljava elementom vatre…

yo vāyodhātuṁ abhinandati, dukkhaṁ so abhinandati. Onaj ko se oduševljava elementom vazduha, oduševljava se patnjom.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. A onaj ko se oduševljava patnjom, kažem vam, ne oslobađa se patnje.

Yo ca kho, bhikkhave, pathavīdhātuṁ nābhinandati, dukkhaṁ so nābhinandati. Onaj ko se ne oduševljava elementom zemlje, ne oduševljava se patnjom.

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmi. A onaj ko se oduševljava patnjom, kažem vam, oslobođen je patnje.

Yo āpodhātuṁ …pe… Onaj ko se ne oduševljava elementom vode…

yo tejodhātuṁ … Onaj ko se ne oduševljava elementom vatre…

yo vāyodhātuṁ nābhinandati, dukkhaṁ so nābhinandati. Onaj ko se ne oduševljava elementom vazduha, ne oduševljava se patnjom.

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmī”ti. A onaj ko se ne oduševljava patnjom, kažem vam, oslobađa se patnje.”

Chaṭṭhaṁ.
