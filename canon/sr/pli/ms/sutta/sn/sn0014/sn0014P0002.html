Saṁyutta Nikāya 14.2 Budini govori tematski grupisani 14.2

1. Nānattavagga 1. Raznolikost

Phassanānattasutta Raznolikost kontakata

Sāvatthiyaṁ viharati. Kraj Sāvatthīja.

“Dhātunānattaṁ, bhikkhave, paṭicca uppajjati phassanānattaṁ. „Monasi, raznolikost elemenata je uslov za nastanak raznolikosti kontakata.

Katamañca, bhikkhave, dhātunānattaṁ? „A šta je to, monasi, raznolikost elemenata?

Cakkhudhātu sotadhātu ghānadhātu jivhādhātu kāyadhātu manodhātu—Element oka, element uha, element nosa, element jezika, element tela, element razuma:

idaṁ vuccati, bhikkhave, dhātunānattaṁ. to se naziva raznolikošću elemenata.

Kathañca, bhikkhave, dhātunānattaṁ paṭicca uppajjati phassanānattaṁ? A kako je to, monasi, raznolikost elemenata uslov za nastanak raznolikosti kontakata.

Cakkhudhātuṁ, bhikkhave, paṭicca uppajjati cakkhusamphasso. Element oka je uslov za nastanak kontakata oka.

Sotadhātuṁ paṭicca … Element uha je uslov za nastanak kontakata uha.

ghānadhātuṁ paṭicca … Element nosa je uslov za nastanak kontakata nosa.

jivhādhātuṁ paṭicca … Element jezika je uslov za nastanak kontakata jezika.

kāyadhātuṁ paṭicca … Element tela je uslov za nastanak kontakata tela.

manodhātuṁ paṭicca uppajjati manosamphasso. Element razuma je uslov za nastanak kontakata razuma.

Evaṁ kho, bhikkhave, dhātunānattaṁ paṭicca uppajjati phassanānattan”ti. Na taj način, monasi, raznolikost elemenata jeste uslov za nastanak raznolikosti kontakata.”

Dutiyaṁ.
