Saṁyutta Nikāya 14.11 Budini govori tematski grupisani 14.11

2. Dutiyavagga 2. Drugo poglavlje

Sattadhātusutta Sedam elemenata

Sāvatthiyaṁ viharati. Kraj Sāvatthija.

“Sattimā, bhikkhave, dhātuyo. „Monasi, sedam je elemenata.

Katamā satta? Kojih sedam?

Ābhādhātu, subhadhātu, ākāsānañcāyatanadhātu, viññāṇañcāyatanadhātu, ākiñcaññāyatanadhātu, nevasaññānāsaññāyatanadhātu, saññāvedayitanirodhadhātu—Element svetlosti, element lepote, element područja beskrajnog prostora, element područja beskrajne svesti, element područja ničega, element područja ni neopažanja ni neopažanja, element prestanka opažaja i osećaja.

imā kho, bhikkhave, satta dhātuyo”ti. To su, monasi, sedam elemenata.”

Evaṁ vutte, aññataro bhikkhu bhagavantaṁ etadavoca: Kad je ovo bilo izrečeno, neki monah ovako reče Blaženome:

“yā cāyaṁ, bhante, ābhādhātu yā ca subhadhātu yā ca ākāsānañcāyatanadhātu yā ca viññāṇañcāyatanadhātu yā ca ākiñcaññāyatanadhātu yā ca nevasaññānāsaññāyatanadhātu yā ca saññāvedayitanirodhadhātu—imā nu kho, bhante, dhātuyo kiṁ paṭicca paññāyantī”ti? „Poštovani, element svetlosti… element prestanka opažaja i osećaja: na osnovu čega su ti elementi prepoznatljivi?”

“Yāyaṁ, bhikkhu, ābhādhātu—ayaṁ dhātu andhakāraṁ paṭicca paññāyati. „Monasi, element svetlosti je prepoznatljiv zahvaljujući mraku.

Yāyaṁ, bhikkhu, subhadhātu—ayaṁ dhātu asubhaṁ paṭicca paññāyati. Element lepote je prepoznatljiv zahvaljujući ružnom.

Yāyaṁ, bhikkhu, ākāsānañcāyatanadhātu—ayaṁ dhātu rūpaṁ paṭicca paññāyati. Element područja beskrajnog prostora je prepoznatljiv zahvaljujući obliku.

Yāyaṁ, bhikkhu, viññāṇañcāyatanadhātu—ayaṁ dhātu ākāsānañcāyatanaṁ paṭicca paññāyati. Element područja beskrajne svesti je prepoznatljiv zahvaljujući području beskrajnog prostora.

Yāyaṁ, bhikkhu, ākiñcaññāyatanadhātu—ayaṁ dhātu viññāṇañcāyatanaṁ paṭicca paññāyati. Element područja ništavila je prepoznatljiv zahvaljujući području beskrajne svesti.

Yāyaṁ, bhikkhu, nevasaññānāsaññāyatanadhātu—ayaṁ dhātu ākiñcaññāyatanaṁ paṭicca paññāyati. Element područja ni neopažanja ni neopažanja je prepoznatljiv zahvaljujući području ničega.

Yāyaṁ, bhikkhu, saññāvedayitanirodhadhātu—ayaṁ dhātu nirodhaṁ paṭicca paññāyatī”ti. Element prestanka opažaja i osećaja je prepoznatljiv zahvaljujući prestanku.”

“Yā cāyaṁ, bhante, ābhādhātu yā ca subhadhātu yā ca ākāsānañcāyatanadhātu yā ca viññāṇañcāyatanadhātu yā ca ākiñcaññāyatanadhātu yā ca nevasaññānāsaññāyatanadhātu yā ca saññāvedayitanirodhadhātu—imā nu kho, bhante, dhātuyo kathaṁ samāpatti pattabbā”ti? „Ali ,poštovani, element svetlosti… element prestanka opažaja i osećaja: kako se postiže dostizanje ovih elemenata?”

“Yā cāyaṁ, bhikkhu, ābhādhātu yā ca subhadhātu yā ca ākāsānañcāyatanadhātu yā ca viññāṇañcāyatanadhātu yā ca ākiñcaññāyatanadhātu—imā dhātuyo saññāsamāpatti pattabbā. „Monasi, element svetlosti, element lepote, element područja beskrajnog prostora, element područja beskrajne svesti i element područja ničega postižu se kao dostignuće u opažanju.

Yāyaṁ, bhikkhu, nevasaññānāsaññāyatanadhātu—ayaṁ dhātu saṅkhārāvasesasamāpatti pattabbā. Element područja ni neopažanja ni neopažanja postiže se kao dostignuće u pogledu preostalih mentalnih obrazaca.

Yāyaṁ, bhikkhu, saññāvedayitanirodhadhātu—ayaṁ dhātu nirodhasamāpatti pattabbā”ti. Element prestanka opažaja i osećaja postiže se kao dostignuće prestanka.”

Paṭhamaṁ.
