Saṁyutta Nikāya 35.19 Budini govori tematski grupisani 35.19

2. Yamakavagga 2. Parovi

Paṭhamābhinandasutta Oduševljenje (1)

“Yo, bhikkhave, cakkhuṁ abhinandati, dukkhaṁ so abhinandati. „Monasi, onaj ko se oduševljava okom, oduševljava se patnjom.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. A onaj ko se oduševljava patnjom, kažem vam, ne oslobađa se patnje.

Yo sotaṁ …pe… Onaj ko se oduševljava uhom…

yo ghānaṁ …pe… nosom…

yo jivhaṁ abhinandati, dukkhaṁ so abhinandati. jezikom…

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi.

Yo kāyaṁ …pe… telom…

yo manaṁ abhinandati, dukkhaṁ so abhinandati. Onaj ko se oduševljava umom, oduševljava se patnjom.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. A onaj ko se oduševljava patnjom, kažem vam, ne oslobađa se patnje.

Yo ca kho, bhikkhave, cakkhuṁ nābhinandati, dukkhaṁ so nābhinandati. „Monasi, onaj ko se ne oduševljava okom, ne oduševljava se patnjom.

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmi. A onaj ko se ne oduševljava patnjom, kažem vam, oslobađa se patnje.

Yo sotaṁ …pe… Onaj ko se ne oduševljava uhom…

yo ghānaṁ …pe… nosom…

yo jivhaṁ nābhinandati, dukkhaṁ so nābhinandati. jezikom…

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmi.

Yo kāyaṁ …pe… telom…

yo manaṁ nābhinandati, dukkhaṁ so nābhinandati. Onaj ko se ne oduševljava umom, ne oduševljava se patnjom.

Yo dukkhaṁ nābhinandati, ‘aparimutto so dukkhasmā’ti vadāmi.” A onaj ko se ne oduševljava patnjom, kažem vam, oslobađa se patnje.”

Sattamaṁ.
