Saṁyutta Nikāya 22.29 Budini govori tematski grupisani 22.29

3. Bhāravagga 3. Teret

Abhinandanasutta Oduševljavanje

Sāvatthinidānaṁ. Kraj Sāvatthīja.

“Yo, bhikkhave, rūpaṁ abhinandati, dukkhaṁ so abhinandati. „Monasi, onaj ko se oduševljava materijalnim oblikom, oduševljava se patnjom.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. A onaj ko se oduševljava patnjom, kažem vam, ne oslobađa se patnje.

Yo vedanaṁ abhinandati … Onaj ko se oduševljava osećajem…

yo saññaṁ abhinandati … opažajem…

yo saṅkhāre abhinandati … mentalnim obrascima…

yo viññāṇaṁ abhinandati, dukkhaṁ so abhinandati. Onaj ko se oduševljava svešću, oduševljava se patnjom.

Yo dukkhaṁ abhinandati, ‘aparimutto so dukkhasmā’ti vadāmi. A onaj ko se oduševljava patnjom, kažem vam, ne oslobađa se patnje.

Yo ca kho, bhikkhave, rūpaṁ nābhinandati, dukkhaṁ so nābhinandati. Ali, monasi, ko god se ne oduševljava oblikom, ne oduševljava se patnjom.

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmi. A onaj ko se ne oduševljava patnjom, kažem vam, oslobađa se patnje.

Yo vedanaṁ nābhinandati … Onaj ko se ne oduševljava osećajem…

yo saññaṁ nābhinandati … opažajem…

yo saṅkhāre nābhinandati … mentalnim obrascima…

yo viññāṇaṁ nābhinandati, dukkhaṁ so nābhinandati. Onaj ko se ne oduševljava svešću, ne oduševljava se patnjom.

Yo dukkhaṁ nābhinandati, ‘parimutto so dukkhasmā’ti vadāmī”ti. A onaj ko se ne oduševljava patnjom, kažem vam, oslobađa se patnje.”

Aṭṭhamaṁ.
